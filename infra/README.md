# Сервер пилота mill

Сервер использует [compose.server.yaml](../compose.server.yaml). Он запускает Next.js в production-режиме, FastAPI с миграциями, PostgreSQL и S3-совместимое хранилище SeaweedFS. Данные PostgreSQL и объекты хранятся в именованных томах. Системный Caddy обслуживает HTTPS. Интерфейс закрыт дополнительным паролем пилота. Запросы к /content-mill/ проходят в закрытый бакет по подписанным ссылкам для загрузки и скачивания.

Код на сервере находится в /opt/mill. Параметры развёртывания и ключи хранятся в /etc/mill/server.env, вход Codex для этого пилота — в /etc/mill/codex/auth.json. Копия входа с рабочего компьютера содержит только временную авторизацию. После истечения сессии для монтажа потребуется обновить вход.

Чтобы подключить готовые ключи озвучки и Avatar 6, обновите LUMEAN_API_KEY и HEYGEN_API_KEY на сервере и примените настройки:

```bash
cd /opt/mill
docker compose -p mill --env-file /etc/mill/server.env -f compose.server.yaml up -d backend
```

Проверка доступности включает /health по локальному порту 18000, вход на домене по HTTPS, экран создания ролика и чтение загруженного файла через временную ссылку. Для проверки Codex достаточно дать модели короткий тестовый клип и проверить узнаваемую деталь в ответе. Этот запрос расходует квоту подписки. Проверку через реальный заказ HeyGen проводят отдельно с подключённым API-кошельком.
