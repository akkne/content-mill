# Content Mill

Content Mill — проект платформы для анализа ниши, подготовки коротких видео, контент-планирования, публикации и оценки результатов. Подробный состав возможностей описан в [функциональной спецификации](docs/features-description.md).

## Состояние репозитория

Сейчас доступны документация и автономный демонстрационный интерфейс [frontend-mvp/index.html](frontend-mvp/index.html). Он работает на моковых данных и описан в [задании MVP](docs/mvp.md). Серверное приложение, приложение Next.js и Docker Compose ещё не созданы.

## Планируемая реализация

- Один монолит на Python в `backend/`.
- Интерфейс на Next.js и Tailwind CSS в `frontend/`.
- PostgreSQL для структуры и метаданных базы знаний; S3-совместимое хранилище для файлов.
- Локальный запуск приложений через Docker и Docker Compose.

Это целевая структура, а не описание уже работающего контура. Выбор контрактов API, фонового выполнения, конкретного S3-провайдера и внешних интеграций отложен до соответствующих задач. Подробнее: [архитектура](docs/architecture.md), [технологический стек](docs/tech-stack.md) и [краткий роадмап](docs/implementation-roadmap.md).
