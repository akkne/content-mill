# Найди хук, которое ролик сможет оправдать

Используй утверждённый тезис, подтверждённые детали и доступные кадры. Предложи разные способы начать с действия, наблюдаемой детали или короткого вопроса. Оставь только варианты, для которых в этом ролике есть ответ. Учитывай голос бренда и язык брифа.

Для каждого варианта дай первую произносимую фразу, первый кадр, вопрос зрителя и конкретную сцену, где он получит ответ. Объясни выбор одной строкой. Если доступна только одна сильная связка фразы и кадра, покажи её. Избегай обещаний результата, которого исходники не демонстрируют.
