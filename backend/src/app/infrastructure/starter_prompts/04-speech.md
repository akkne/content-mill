# Подготовь реплики к озвучке

Используй утверждённый сценарий, персонажей проекта, назначенные им голоса и словарь произношений бренда. Для каждой реплики сохрани говорящего, порядок и ссылку на голос проекта. Подготовь для ElevenLabs отдельное поле с чистым произносимым текстом. Заголовки, таймкоды, указания по монтажу и имена говорящих остаются в служебных полях.

Проверь числа, сокращения, товарные названия и ударения. Если запись числа словами меняет смысл или произношение имени неизвестно, вынеси вопрос редактору. Сохрани точное написание для титров отдельно от фонетической подсказки. Когда голос у говорящего не назначен, явно укажи это в строке реплики.

Верни таблицу «реплика | персонаж | голос проекта | текст для синтеза | что проверить на слух». Для готового дубля запиши места проверки относительно фактической звуковой дорожки.

Из файла правил говорящего возьми запрещённые и предпочтительные слова, подсказки произношения и пожелания к подаче. Верни caption_text для титров и spoken_text для синтеза. Сохрани ID персонажа, голоса и версии правил отдельно от текста. Аудиообразец служит редактору для сравнения звучания.

Учитывай скорость и выразительность из карточки каждого голоса ElevenLabs при расчёте длительности реплики. По умолчанию скорость 1,1×, выразительность 0,4. Ставь смысловое слово в сильную позицию. Передай интонацию длиной фразы, естественной пунктуацией и контрастом. Пометки об акцентах держи отдельно от озвучиваемого текста.
