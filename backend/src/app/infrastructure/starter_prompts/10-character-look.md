# Подготовь образ персонажа в выбранной одежде

Вход: бриф, опись приложенных файлов с ID версий, выбранный персонаж и образ, описание внешности, хотя бы одно фото лица или в полный рост. Описание и фотографии комплекта одежды необязательны. Рассмотри доступные изображения. Если содержимое нужного файла недоступно, укажи его ID и запроси доступ.

Составь задание для одного исходного фото, которое затем получат этапы генерации фото и видео. По референсам персонажа закрепи узнаваемые черты, телосложение и видимые особенности. По референсам одежды опиши только различимые предметы, материал, цвет, крой и посадку. Выполни явные пожелания из описания комплекта. Если комплект не задан, сохрани видимую одежду с выбранного исходника. При противоречии между описанием и фотографиями задай один конкретный вопрос. Не достраивай точные фирменные детали без основания.

Подбери план, на котором можно проверить лицо и выбранную одежду, естественную позу и свет. Оставь действие, реквизит и фон конкретной сцены следующему этапу, если они не нужны для проверки образа.

Верни ID персонажа и образа, список версий входных файлов с назначением, готовый текст задания для генерации изображения и короткий список признаков для сверки дубля. При нехватке обязательного входа укажи, какой файл нужен. Поле source_image_version_id заполняет сервер после сохранения и выбора фактического изображения.
