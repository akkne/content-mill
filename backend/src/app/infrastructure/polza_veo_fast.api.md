# Veo 3.1 Fast в Polza AI

## Контракт адаптера

Сверка источников — 22 ноября 2026.

```http
POST https://polza.ai/api/v1/media
Authorization: Bearer <key>
Content-Type: application/json

{"model":"google/veo3_fast","async":true,"input":{"prompt":"…","images":[{"type":"base64","data":"data:image/png;base64,…"}],"aspect_ratio":"9:16","generationType":"FIRST_AND_LAST_FRAMES_2_VIDEO","enableTranslation":"false"}}
```

Успешная отправка возвращает строковый `id`. Content Mill хранит его с префиксом `polza:`. Опрос выполняется через `GET /api/v1/media/{id}` с тем же ключом. Статусы `pending` и `processing` продолжают ожидание, `failed` и `cancelled` завершают заказ. При `completed` адаптер принимает обе формы результата.

```json
{"status":"completed","data":{"url":"https://s3.polza.ai/result"}}
```

```json
{"status":"completed","data":[{"url":"https://s3.polza.ai/result"}]}
```

Первая форма приведена в справочнике. Вторая получена 22.11.2026 при чтении готового изображения. Для одного запрошенного файла берём первый элемент. Скачивание — отдельный GET по HTTPS на polza.ai или его поддомен, без API-ключа. Пустой результат, посторонний адрес и сбой скачивания оставляют сохранённый ID для повтора чтения. Таймаут HTTP 120 секунд для API и 90 для скачивания, ожидание стадии в приложении до 30 минут. HTTP 401/403 означают отсутствие доступа, 402 — проблему баланса, 429 — ограничение запросов. [Создание](https://polza.ai/docs/api-reference/media/create) · [Статус](https://polza.ai/docs/api-reference/media/status)

В этом режиме передаём один стартовый кадр. Поле перевода — строковое перечисление. Каталог отдельно описывает до трёх изображений в режиме REFERENCE_2_VIDEO, seed 10000–99999 и watermark до 50 символов. Эти параметры адаптер опускает. Локальный предел входного PNG 8 000 000 байт на выходе генератора кадров, полезная нагрузка base64 занимает 4 × ceil(байты / 3) символов. Результат — один восьмисекундный исходник. Каталог указывает 45 ₽ за запрос. [Параметры и тарифы](https://polza.ai/api/v1/models)

## Ограничения и эксплуатация

Статус — активна. На 21 ноября 2026 года каталог содержит `google/veo3_fast`. POST /api/v1/media принимает серверный Bearer POLZA_API_KEY, модель, async=true и input. Передаём стартовый PNG в images с типом base64, режим FIRST_AND_LAST_FRAMES_2_VIDEO, 9:16 и enableTranslation=false для сохранения языка реплик. Звук генерируется вместе с клипом, а сервер проверяет наличие аудио перед монтажом. Гайд указывает 2000 символов промпта, текущий каталог указывает 60 000. Приложение для новых сцен использует меньший предел. Общий предел запроса и ответа в битах не опубликован. [Гайд](https://polza.ai/docs/gaidy/veo-3-1) · [Каталог API](https://polza.ai/api/v1/models)

Ответ содержит ID для GET /api/v1/media/{id}. При completed скачиваем MP4 по URL результата без авторизации, ограничиваем 64 МиБ, затем сохраняем в проект. Файлы у провайдера хранятся семь дней. Тарификация за видео, права, баланс и квоты зависят от аккаунта. Опрос возобновляется по сохранённому ID. Повторная отправка после отказа либо потери ответа может списать средства. [Модель и тариф](https://polza.ai/models/google/veo3_fast) · [Адаптер](polza_veo_fast.py)

При сборке ролика карточка показывает причину ошибки заказа и отдельно сохраняет HTTP-статус при ошибке запроса. [Диагностика генерации](../../../../docs/decisions/0024-video-failures.md)
