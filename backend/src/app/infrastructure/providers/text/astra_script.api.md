# OpenAI GPT-6.2-Astra через Codex

## Контракт адаптера

Сверка источников — 22 ноября 2026.

```text
codex exec --ephemeral --model gpt-6.2-astra -c 'model_reasoning_effort="high"' -c 'developer_instructions=…' [--image preview.jpg …] --output-last-message result.txt -
stdin: пользовательский текст UTF-8
result.txt: последнее сообщение UTF-8
```

Для сценария приложение ожидает JSON с полями script, caption и edit_plan. Раскадровка и монтаж получают JSON Schema в поле schema, ответ проверяет Pydantic. Для монтажа локальный MCP предоставляет inspect_frame, listen и inspect_material. Раскадровка ожидает ответ CLI без ограничения времени. Через inspect_material модель читает выбранные исходники и медиа назначенных аватаров по ID версии. Для подготовки сценария таймаут составляет 120 секунд, для монтажа 600. HTTP-тело CLI формирует самостоятельно.

Паспорт модели API указывает 1 050 000 токенов контекста, до 922 000 входных и до 128 000 выходных токенов. Доступный бюджет CLI зависит также от системных сообщений и инструментов. Прямой ввод модели — текст и изображения, выход — текст. [Паспорт Astra](https://developers.openai.com/api/docs/models/gpt-6.2-astra)

## Ограничения и эксплуатация

Активная модель для новых текстовых запросов Content Mill — `gpt-6.2-astra`. На 21 ноября 2026 года локальный каталог Codex CLI содержит эту модель и уровень рассуждения `high`. Доступ и квоты зависят от аккаунта.

[Адаптер](astra_script.py) вызывает Codex CLI 0.170.0 в отдельном временном каталоге. Инструкции передаются через конфигурацию, текст через stdin, превью JPEG через файлы. CLI записывает финальный текст в UTF-8. При завершении процесса Content Mill удаляет каталог. При отказе провайдера операция завершается ошибкой. Новый запуск повторно расходует квоту.

Общие ограничения числа символов, размера обмена в битах и размера результата для этой модели через CLI не подтверждены. Доступность, тариф и условия обработки данных определяет аккаунт OpenAI. [Codex CLI](https://developers.openai.com/codex/cli/) · [Аутентификация](https://developers.openai.com/codex/auth/) · [Изменения](https://developers.openai.com/codex/changelog/)

Для локального входа через ChatGPT подключите Compose-файл по [решению 0017](../../../../../../docs/decisions/0017-local-codex-login.md). Каждая генерация расходует квоту подключённого аккаунта.

При монтаже сессия получает до десяти минут на просмотр исходников и выдачу монтажного листа. В CLI 0.170.0 инструмент чтения аудио может передать осциллограмму как PNG. Для клиентов с поддержкой аудио доступна выдача MP3. [Формат задания монтажёру](../../../../../../docs/decisions/0020-video-dialogue-and-edit.md).

Для рилса со спикером generate по отдельным JSON Schema выбирает диапазоны расшифровки, составляет план иллюстраций по фразам и выбирает слова для выделения в титрах. [Порядок этапов и артефакты](../../../../../../docs/decisions/0042-talking-head-overlays.md).

26 ноября 2026 года проверен вызов generate_edit для прозрачной анимации. Вход включает описание сцены и движения, язык, длительность в миллисекундах, слова с относительными таймкодами, кадр исходника и выбранные изображения-референсы. Ответ содержит 2–18 векторных слоёв на холсте 600 × 360. Каждый слой задаёт SVG-фрагмент до 12 000 символов и 1–16 ключевых кадров с нормированным временем, смещением, масштабом, поворотом, непрозрачностью, раскрытием и кривой интерполяции. Модель может расставить до пяти точек фоли. Контракт и ограничения приложения проверяет [MotionScore](../../../application/videos/motion_score.py). При ошибке формата модель получает одно уточнение. После сохранения описания отдельный локальный этап рендерит прозрачный WebM. [Решение и контрольный пример](../../../../../../docs/decisions/0043-gpt-motion.md).

С 26 ноября 2026 года новый сценарий использует планы по 3000–4000 мс с чередованием точек съёмки. Монтажёр выбирает интервалы белых вставок по словам чернового монтажа, анимация использует портретный холст 360 × 640. [Тайминг и звуковая дорожка](../../../../../../docs/decisions/0044-shot-rhythm.md).
