# GPT-6.2-Sol через Codex CLI

Текущая конфигурация mill выбирает gpt-6.2-sol и model_reasoning_effort="high". Форматы входных материалов, локальные инструменты просмотра и формат результата совпадают с [контрактом общего вызова Codex](astra_script.api.md). Для монтажа вход включает раскадровку и клипы, на выходе приложение проверяет монтажный лист и собирает MP4 через FFmpeg. При входе ChatGPT запросы расходуют квоту подключённой подписки.
