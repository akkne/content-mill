# Claude Opus 5.5 через Polza AI

Проверено 28 ноября 2026 года. [Каталог и тариф модели](https://polza.ai/models/anthropic/claude-opus-5.5), [интерфейсы Polza](https://polza.ai/software-registry/functional-characteristics), [подключение к Messages API](https://polza.ai/integrations/claude-desktop).

## Запрос и результат

[Адаптер](polza_opus.py) реализует MontageModel. Каждый шаг делает синхронный POST на `https://polza.ai/api/v1/messages` с JSON, заголовками `Authorization: Bearer <POLZA_API_KEY>` и `anthropic-version: 2023-06-01`. Ключу нужен доступ к модели. Отдельного заказа, опроса или ссылки для скачивания нет.

```json
{
  "model": "anthropic/claude-opus-5.5",
  "system": "Инструкция этапа",
  "max_tokens": 16384,
  "messages": [{"role": "user", "content": [
    {"type": "text", "text": "Задание и JSON Schema"},
    {"type": "image", "source": {"type": "base64", "media_type": "image/jpeg", "data": "…"}}
  ]}]
}
```

Опциональный массив `tools` содержит объекты с полями `name: string`, `description: string`, `input_schema: object`. При `stop_reason=tool_use` ответ содержит блоки `{type, id, name, input}`. Следующий запрос включает этот ответ в роли assistant и блоки user типа `tool_result` с `tool_use_id` и результатом чтения. Монтаж может запросить кадр, осциллограмму, выбранный материал или описание привязанного шаблона OpenMotion. Сервер передаёт текст или изображение JPEG/PNG в base64. При `stop_reason=end_turn` приложение объединяет строки `content[].text` из блоков типа text и валидирует JSON по схеме этапа. Итоговый MP4 создаёт локальный рендерер.

## Ограничения

Каталог указывает контекст 1M и максимальный ответ 128K токенов. Адаптер запрашивает до 65 536 выходных токенов для подробной раскадровки и до 16 384 для монтажа. На один этап отведено до 32 обращений к API для просмотра материалов, таймаут ожидания данных HTTP составляет 300 секунд. Каждый вызов тарифицируется по токенам. Запрос с транспортной ошибкой автоматически не повторяется. Пределы символов, количества и размера изображений, размеры целого запроса и ответа в битах, квота запросов и срок хранения для конкретного маршрута в карточке модели не опубликованы. Base64 занимает четыре символа на каждые три байта с округлением вверх до полного блока.

HTTP-ошибки проходят через штатную диагностику сборки. При проверке с ключом без доступа к модели шлюз вернул HTTP 403 и код FORBIDDEN. Для повторной проверки используйте ключ с разрешением на модель и тестовое задание без клиентских данных. [Тесты контракта](../../../../../tests/test_polza_opus.py).
