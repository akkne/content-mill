# Локальное распознавание речи Whisper

Проверено 25 ноября 2026. Метод `transcribe(media, fmt, language)` получает байты MP4 или WebM и код языка `ru` или `en`. Результат — список слов вида `{"start_ms": 240, "end_ms": 680, "text": "And"}`. Время отсчитывается от начала контейнера. При отсутствии речи возвращается пустой список.

Монолит запускает faster-whisper на CPU с int8, VAD и временными границами слов. По умолчанию используются многоязычные веса small. Первый вызов загружает веса в кэш Hugging Face. В Compose кэш хранится в томе whisper_models. Для работы без доступа к сети можно смонтировать локальную модель CTranslate2 и задать путь в CONTENT_MILL_WHISPER_MODEL. Исходная запись обрабатывается локально. Для выбора отрывка GPT получает расшифровку. Ограничение загрузки базы знаний составляет 64 МиБ на файл, предельная длительность распознавания — три часа.

[Документация faster-whisper](https://github.com/SYSTRAN/faster-whisper) · [Модель small](https://huggingface.co/Systran/faster-whisper-small) · [Адаптер](local_whisper.py).
