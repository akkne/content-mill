# Каталог голосов ElevenLabs

## Контракт адаптера

Сверка источников — 22 ноября 2026.

```http
GET https://api.elevenlabs.io/v2/voices?page_size=20&include_total_count=false
xi-api-key: <key>
```

```json
{"voices":[{"voice_id":"id","name":"Имя","labels":{"gender":"male","language":"en"},"verified_languages":[{"language":"en","preview_url":"https://…"}],"preview_url":"https://…"}],"has_more":true,"next_page_token":"cursor"}
```

Обязательные поля для чтения — voices, voice_id и has_more. Следующую страницу запрашиваем с next_page_token. Описание, метки и ссылки могут отсутствовать. [Схема страницы](https://elevenlabs.io/docs/api-reference/voices/search)

## Ограничения и эксплуатация

Статус — отключена. Действующее подключение описано в [карточке Lumean](../../../../../../docs/integrations/lumean-eleven-multilingual-v2.md).

Адаптер метаданных общего рабочего аккаунта. Проверено по документации 19 ноября 2026 года. Операция чтения каталога доступна при настройке серверного ключа с правом чтения голосов.

[GET /v2/voices](https://elevenlabs.io/docs/api-reference/voices/search) возвращает JSON. Передаём ключ в заголовке `xi-api-key`, текст в `search` или точный ID в `voice_ids`, метки `language` и `gender`, а также курсор `next_page_token`. Запрашиваем 20 записей, общий счётчик отключён. Максимальный запрашиваемый размер страницы и число ID в одном запросе равны 100. Общий предел размера HTTP-ответа и отдельная квота запросов в минуту для каталога не опубликованы.

[Адаптер](elevenlabs.py) возвращает только поля карточки, использует пул HTTP-соединений и кеш до 128 страниц на 60 секунд на процесс. После выбора проверяет точный ID тем же методом. Ошибка ключа, таймаут и ограничение частоты отображаются в окне выбора. Повтор инициирует пользователь. Первую страницу можно проверить ключом рабочего аккаунта и сравнить результаты с его коллекцией.

Браузер получает аудио непосредственно по HTTPS-ссылке превью после нажатия. Для сохранённых в проекте пользовательских образцов используется существующая загрузка в S3. Модель синтеза, промпт и генерация аудио в этой операции не участвуют.
