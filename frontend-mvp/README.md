# Автономные демо

В этой папке находятся два независимых интерфейса на моковых данных:

| Путь | Формат | Запуск |
| --- | --- | --- |
| [index.html](index.html) | Основное демо mill с отдельными стилями, скриптами и изображениями. | Открыть файл в браузере, сохраняя папку `frontend-mvp/` целиком. |
| [index-finder.html](index-finder.html) | Вариант основного интерфейса с базой знаний в виде дерева папок. Документы открываются и редактируются в окне файла; видео и аудио воспроизводятся там же. | Открыть файл, сохраняя папку `frontend-mvp/` целиком. |
| [legacy.html](legacy.html) | Прежний однофайловый MVP по [заданию](../docs/mvp.md). | Открыть файл в браузере. |

В основном демо есть демонстрационный экран входа: можно выбрать Google или Microsoft и роль владельца, редактора либо наблюдателя. Это макет SSO, без перенаправления к провайдеру, проверки личности и серверной защиты данных. Выбор роли сохраняется до закрытия вкладки; ограничения доступа работают только в интерфейсе и не защищают данные браузера. Владелец видит все разделы, редактор может работать с контентом, наблюдатель просматривает его без изменений. Для настоящего SSO понадобятся выбранный провайдер и серверная проверка сессии и прав.

Основное демо переключается между русским и английским интерфейсом; выбор языка сохраняется в браузере. Изменения в проекте также сохраняются в локальном хранилище браузера. Генерация, публикации, аналитика и подключения в нём демонстрационные: интеграций с бэкендом и соцсетями нет. Для шрифта используется Google Fonts; при отсутствии сети браузер применит запасной шрифт. Демо не входит в сборку Next.js из `frontend/`.
