# Автономные демо

В этой папке находятся два независимых интерфейса на моковых данных:

| Путь | Формат | Запуск |
| --- | --- | --- |
| [index.html](index.html) | Однофайловый MVP по [заданию](../docs/mvp.md). | Открыть файл в браузере. |
| [mill-site/index.html](mill-site/index.html) | Визуальная концепция mill с отдельными стилями, скриптами и изображениями. | Открыть файл в браузере, сохраняя папку `mill-site/` целиком. |

Визуальная концепция сохраняет изменения в локальном хранилище браузера. Генерация, публикации, аналитика и подключения в ней демонстрационные: интеграций с бэкендом и соцсетями нет. Для шрифта используется Google Fonts; при отсутствии сети браузер применит запасной шрифт. Демо не входит в сборку Next.js из `frontend/`.
