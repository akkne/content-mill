# 0015. Выбор CLI для серверных сценариев

Разработчик задаёт `CONTENT_MILL_SCRIPT_PROVIDER` в серверном окружении. Значения `codex` и `claude` выбирают неинтерактивный Codex CLI и Claude Code CLI соответственно. Пустое значение сохраняет прежний выбор HTTP API по `CONTENT_MILL_SCRIPT_MODEL` и доступным ключам. Бэкенд отклоняет неизвестное имя провайдера при запуске.

Очередь фиксирует способ запуска и модель при создании задания. После переключения ранее созданные задания используют прежний адаптер, пока доступен его ключ. При отсутствии ключа выбранного провайдера новые задания недоступны.

Образ бэкенда содержит обе CLI. На каждый вызов создаётся временный каталог. Процесс получает данные проекта через stdin и только ключ своего провайдера. Claude получает изображения в сообщении, Codex получает подготовленные JPEG как вложения. Внешние инструменты для чтения проекта не требуются: каталог, документы и превью предоставляет Content Mill.
