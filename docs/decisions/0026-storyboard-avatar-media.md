# 0026. Источники раскадровки и ожидание Codex

Выбранные пользователем версии задают творческую основу сценария и раскадровки. При сборке сервер дополняет их фотографиями и видео назначенных персонажей из проекта и связанной личной библиотеки владельца. Папки разрешений исключены. Документы и промпты участвуют в качестве материалов по явному выбору. Сборка закрепляет копии исходников в папке ролика в S3. Модель получает каталог и читает оригиналы через inspect_material, затем выбирает версии для каждого кадра.

Раскадровка ждёт завершения Codex CLI без локального таймаута. Пока обработчик работает, он продлевает захват задания. После остановки процесса сохраняется обычное обнаружение прерванного задания.
