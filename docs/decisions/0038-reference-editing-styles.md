# Стили монтажа по двум примерам с ведущей

«История в цифрах» использует приёмы ролика про Apple: факт в завязке, наглядное объяснение величины, короткие титры с лаймовым акцентом. «История через детали» использует приёмы ролика про дом: решение героя, переход с общего плана на предмет, сохранение голоса на вставке, возврат к выводу. Материалы примеров служат для анализа монтажа.

Обе инструкции находятся в [каталоге стилей](../../backend/src/app/domain/video.py). Выбранная инструкция поступает сценаристу, в раскадровку и на сборку монтажного листа. В поле emphasis модель может отметить точную фразу из субтитра. Рендер выделяет её цветом. Для стиля про детали выбранное фото вписывается в карточку с полями. Содержимое и таймкод вставки зависят от выбранных материалов и сценария.
