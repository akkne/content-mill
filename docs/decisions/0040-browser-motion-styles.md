# Два стиля монтажа в мастере роликов

Мастер и настройки проекта используют общий список стилей. «Аватар с моушн-графикой» сохраняет фон с ведущим, помещает сравнения поверх кадра и анимирует акцентные титры. «Текст в интерфейсе» показывает сцену в светлом окне, раскрывая слова над ним по таймкодам фразы. Направление стиля передаётся сценаристу и монтажёру. Сборка использует серверный FFmpeg и работает без запуска OpenMotion на компьютере пользователя.
