# 0009. Доступ агента к материалам проекта по запросу

Для производственного воркфлоу предлагаем дать агенту поиск и чтение по всей доступной пользователю базе знаний текущего проекта. На старте агент получает бриф, список специально приложенных версий и их назначения. Остальные материалы он находит по мере необходимости. Пользователь может писать обычные имена или выбирать файлы в интерфейсе. Выбор в интерфейсе сразу закрепляет версию.

## Операции воркфлоу

| Предлагаемый инструмент | Поведение |
| --- | --- |
| `find_assets` | Ищет по имени или тексту, поддерживает отбор по папке, типу и персонажу. Возвращает ограниченную страницу совпадений с названием, путём, типом и ID версии. Для выбранного образа использует связь персонажа с утверждённой версией. |
| `read_document` | Принимает ID версии и диапазон текста. Возвращает содержимое документа или фрагмент с указанием позиции. |
| `preview_asset` | Возвращает уменьшенное изображение или доступные ключевые кадры по ID версии, когда агенту нужно увидеть деталь. Если для файла есть только метаданные, ответ явно указывает это. |

Контекст пользователя, проекта и запуска устанавливает сервер. Каждая операция проверяет текущие права и принадлежность версии проекту. При разрешении имени сначала учитываются явно приложенные версии и роль в сцене, затем путь и персонаж. При нескольких равнозначных кандидатах агент показывает пользователю короткие пути для выбора. При пустой выдаче просит указать другой файл или загрузить его. Для продолжения запуска сервер записывает выбранный version_id, роль и этап. Повтор использует этот выбор даже после переименования или загрузки новой версии файла.

## Транспорт и расход данных

Внутри монолита достаточно представить эти операции модели как вызываемые инструменты и связать их с существующими сценариями базы знаний. Для совместимого внешнего воркфлоу предложен MCP-адаптер тех же операций в FastAPI. Через MCP tools агент самостоятельно инициирует поиск и чтение. Клиент с поддержкой MCP resources может дополнительно открыть конкретную версию по URI. Наличие поддержки MCP и нужных типов результатов проверяется в выбранном клиенте. [MCP Python SDK](https://py.sdk.modelcontextprotocol.io/servers/resources/).

Например, по фразе «Возьми утверждённое фото Анны в синей куртке и трек Рассвет» агент получает две ссылки на версии. При необходимости он открывает превью. В задание генератору сцены уходят ID образа и музыкального фрагмента. Уже адаптер генератора получает из S3 эти версии и передаёт их по временной ссылке, через загрузку или по действующему ID файла провайдера. Временная ссылка работает, только если адрес хранилища доступен провайдеру. Для локального S3 понадобится серверная загрузка либо доступное извне хранилище.

Прочитанный текст и показанное превью занимают контекст модели. Выигрыш даёт выборочное чтение и повторное использование версии или загрузки в пределах разрешённого аккаунта и срока действия. MCP сам не уменьшает стоимость обработки изображения или видео.

Поиск проекта, чтение версий и выдача временных ссылок уже есть в приложении. Инструменты агента, MCP-адаптер и извлечение видеопревью описаны для будущей реализации. [Формат пакета запуска](../video-agent-handoff.md).
