# Выбор материалов для ролика

В мастере ролика база знаний открывается в модальном окне. Один клик выделяет файл или папку, повторный снимает выделение. Двойной клик по папке или кнопка со стрелкой открывает её. Выделение сохраняется при переходе между папками. Кнопка «Выбрать» применяет выбор, «Отмена» и Escape закрывают окно без изменений.

Папка добавляет последние сохранённые версии файлов во всех её подпапках. Отдельный файл можно выбрать в конкретной версии. При пересечении выборок одна версия передаётся один раз. Ролик сохраняет ссылки на версии файлов, поэтому дальнейшие изменения папки не меняют состав уже созданного ролика.
