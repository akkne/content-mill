# 0049. Выбор провайдера монтажа в окружении сервера

28 ноября 2026 года. Сборщик видео получает реализацию существующего контракта MontageModel из серверной настройки `CONTENT_MILL_MONTAGE_PROVIDER`. Значение `codex` выбирает прежнюю Astra через CLI, `polza` выбирает Claude Opus 5.5 через Messages API. Выбор применяется при запуске бэкенда ко всем последующим шагам очереди, в том числе при продолжении сборки ранее созданного ролика. Сценарии и текст черновика используют свой `CONTENT_MILL_SCRIPT_PROVIDER`.

Оба адаптера готовят для модели один и тот же набор разрешённых материалов. Бэкенд выполняет инструменты просмотра локально, проверяет ответ по схеме этапа и передаёт монтажный лист рендереру. Ошибка доступа к выбранному провайдеру останавливает задание. [Карточка интеграции](../integrations/polza-claude-opus-5.5.md).
