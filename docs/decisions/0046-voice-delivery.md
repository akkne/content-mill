# Настройки подачи для каждого голоса

26 ноября 2026 года. Владелец личной библиотеки при создании и редактировании голоса выбирает скорость речи от 0,7 до 1,2 и выразительность от 0 до 1. Стандартная скорость — 1,1×, выразительность — 0,4. Миграция назначает эти значения существующим карточкам.

Отдельная озвучка получает настройки при регистрации запроса. Ролик сохраняет их вместе с идентификатором голоса и моделью при выборе состава. У ранее сохранённого состава без этих полей используются стандартные значения. Параметры передаются с заказом и действуют для повторно используемых шаблонов.
