# 0032. Стиль монтажа в настройках ролика

Дата принятия — 23 ноября 2026 года.

Формат подачи описывает содержание сценария. Дополнительное поле editing_style задаёт темп, крупность планов и мотив склейки. Мастер предлагает стили «По сценарию», «Динамичный», «Детали товара» и «Спокойный обзор». Сервер передаёт одну инструкцию на этапы подготовки сценария, раскадровки и монтажного листа.

Выбор сохраняется в существующих настройках ролика. Для запросов и сохранённых роликов прежних версий применяется «По сценарию». Добавлен вариант длительности 40 секунд, для которого по действующему правилу планируются пять сцен. Для всех стилей действуют [согласованные границы сцен](0030-kling-scene-windows.md). Монтаж исходного видео клиента описан отдельным будущим сценарием в [плане студии](../content-studio.md).
