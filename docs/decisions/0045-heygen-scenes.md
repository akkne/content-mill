# Генерация исходных видеосцен через HeyGen

26 ноября 2026 года. Все новые заказы исходных видеосцен отправляются в [HeyGen Video 1](../integrations/heygen-video.md) или [Avatar 6](../integrations/heygen-avatar-6.md) для синхронизации ведущего с голосом. Это распространяется и на продолжение черновиков. Работник забирает уже оплаченные заказы прежнего провайдера по сохранённому идентификатору. Обработка загруженных записей, GPT-анимации на белом фоне и итоговый монтаж продолжают использовать [монтаж по репликам](0044-shot-rhythm.md).
