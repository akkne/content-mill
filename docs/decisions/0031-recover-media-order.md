# 0031. Восстановление заказа Polza после обрыва связи

При потере ответа на платный POST провайдер может уже выполнять заказ. Бэкенд сохраняет причину `order_unconfirmed`, модель и время начала запроса. Обычный повтор такого этапа отклоняется. В карточке доступно отдельное действие «Создать новый платный заказ». Для прежних ошибок network и timeout на отправке кадра или клипа действует та же проверка.

Администратор сверяет текущий проект, ролик, сцену, ключ, модель и время запроса с [историей Polza](https://polza.ai/docs/api-reference/history/generations). При неоднозначном совпадении привязку откладывают. Для подтверждённого заказа выполнить:

```sh
docker compose exec backend python -m app.recover_media_order PROJECT_UUID VIDEO_UUID SCENE_NUMBER gen_ORDER_ID
```

Команда проверяет статус и модель в Polza, блокирует запись ролика, проверяет номер остановленной сцены и сохраняет ID для получения результата. В карточке пользователь нажимает «Получить результат заказа». Ближайший шаг использует GET по сохранённому ID; дальнейшая сборка продолжается по сценарию.
