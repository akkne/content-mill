# 0014. Два языка интерфейса

Каждое изменение интерфейса Next.js поставляется с русским и английским текстом в одном PR. Выбранный [язык интерфейса](0012-voice-catalog-language.md) определяет язык страниц, форм, диалогов, сообщений и подписей для скринридеров. Имена и материалы пользователя сохраняют исходный язык.
