# 0002. Голоса проекта и каталог ElevenLabs

Принято 19 ноября 2026 года.

Карточка голоса принадлежит проекту и создаётся внутри системной папки «Голоса». Аватар и будущий сценарий создания ролика используют UUID карточки. В PostgreSQL сохраняем имя, ID ElevenLabs, описание, языки провайдера, пол, ссылку на превью и настройки пользователя. Пол можно уточнить вручную. Загруженные пользователем образцы остаются версионированными объектами в S3. Каталог показывает внешнее демо по запросу слушателя.

Один серверный ключ даёт пользователям проектов доступ к каталогу общего рабочего аккаунта. Для приватного голоса аккаунту нужен доступ. Выбор из каталога и поиск по точному ID используют [List voices](https://elevenlabs.io/docs/api-reference/voices/search). Пользователь также может сохранить известный ID вручную.

На страницу запрашиваем 20 записей с курсором, без подсчёта общего количества. API допускает page_size до 100 и может включить дополнительные стандартные голоса на первой странице. Поиск и фильтры выполняет ElevenLabs, язык фильтруется по метке language. Записи без меток и демо остаются доступны без фильтров. Гарантированный предел запросов в минуту для этого метода не опубликован. При [429](https://elevenlabs.io/docs/eleven-api/resources/errors) пользователь может повторить запрос позднее. Каталог не вызывает синтез речи.
