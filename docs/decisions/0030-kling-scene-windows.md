# 0030. Десятисекундные клипы Kling и тайминги сцен

Kling 2.6 через Polza AI генерирует клип длиной 10 секунд со звуком из стартового кадра. Число сцен по-прежнему определяется при подготовке сценария. Для каждой сцены Codex переносит длительность её интервала из сценария в поле keep_ms файла storyboard.json. Например, интервал готового ролика 00:14–00:22 задаёт keep_ms = 8000, а локальный интервал в десятисекундном исходнике — 0–8 секунд. Сумма интервалов равна длительности ролика.

Сервер добавляет в каждый видеопромпт инструкцию завершить действие и речь за первые keep_ms и удерживать финальное положение до конца дубля. Монтажёр получает раскадровку и инструкцию использовать каждую сцену по порядку от нуля ровно до её keep_ms. Сервер проверяет лист перед рендером FFmpeg, включая длины исходников и сохранность реплик.

Для старой раскадровки при первой новой отправке Codex адаптирует промпты к лимиту Kling и переносит длительности из описания сцен. Результат сохраняется рядом как storyboard-kling.json. Сценарий, исходная раскадровка, уже готовые кадры и идентификаторы текущих заказов сохраняются. Ранее отправленные заказы Polza опрашиваются по прежнему ID.
