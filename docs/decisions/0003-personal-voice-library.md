# 0003. Личная библиотека голосов

Владелец создаёт голос на странице «База знаний → Голоса», даже если у него ещё нет проектов. Здесь доступны каталог ElevenLabs, ручной ID, описание, языки, пол, модель, пример и список проектов с флажками. Плитки «Голоса» и «Аватары» размещены под деревом базы знаний. «Аватары» зарезервированы для следующего этапа.

Карточка принадлежит пользователю. Назначение в проект создаёт узел в его папке «Голоса» со ссылкой на библиотеку. При совпадении имени в папке к имени узла добавляется номер. Изменения свойств в библиотеке распространяются на связанные узлы. Проектное окно показывает только личные голоса и позволяет добавить их без запроса к ElevenLabs. Добавление и снятие отметок сохраняются одной транзакцией.

При снятии отметки проектная папка голоса и её образцы скрываются, а привязка аватара снимается. Повторное назначение возвращает папку и образцы. Загруженные образцы принадлежат конкретному проекту и хранятся в S3. Миграция переносит каждую существующую активную карточку в библиотеку владельца и сохраняет исходные узлы, файлы и связи аватаров. Новые проекты начинают с пустой папки «Голоса».

Это решение обновляет область владения из [решения 0002](0002-elevenlabs-voices.md).
