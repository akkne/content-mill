# 0004. Навигация по личным библиотекам

В общей базе знаний и под деревом проекта доступны одни и те же карточки личных библиотек. «Голоса» открывает существующую библиотеку. «Аватары» ведёт на защищённую страницу `/knowledge/avatars`, которая сообщает о разработке раздела и позволяет вернуться к базе знаний. Аватары конкретного проекта по-прежнему доступны в его дереве.
