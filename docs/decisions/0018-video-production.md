# 0018. Сборка видео из озвученных сцен

Сервер принимает бриф и выбранные версии материалов. Текстовая модель пишет сценарий по документам проекта. Для сборки Codex готовит раскадровку и два запроса на каждую сцену. Nano Banana 2.1 создаёт стартовый кадр. Veo 3.1 Fast получает его и точную реплику персонажа. Собственный звук Veo сохраняется до финального экспорта. Выбранный в мастере голос ElevenLabs доступен для отдельной озвучки сценария.

Очередь внутри монолита хранит этап в videos.settings.production. PostgreSQL блокирует запись на время захвата этапа и на время сохранения результата. Сетевые обращения к AI выполняются между транзакциями. После истечения аренды прерванный этап требует ручного повтора. Уже сохранённые кадры и клипы используются повторно.

Для каждой сборки создаётся папка в базе знаний. Входные версии копируются в неё до раскадровки. MP4, PNG, бриф со снимком промптов, раскадровка и монтажный лист имеют обычные версии в S3. На финальном этапе codex exec получает монтажный бриф, превью и доступ через локальный MCP к кадрам и звуку конкретных исходных клипов. Возвращает монтажный лист с точными интервалами. Для выбранной фоновой дорожки сохраняются версия, отступ и громкость, для субтитров — текст и границы. FFmpeg исполняет склейки, сохраняя исходное взаимное положение дорожек. Статус ready фиксируется в одной транзакции с версией final.mp4 после проверки длительности и дорожек.
