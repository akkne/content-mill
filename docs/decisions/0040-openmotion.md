# Каталог монтажа и локальная OpenMotion Studio

В разделе «Монтаж» карточка показывает опубликованный референс и отдельный исполняемый пример анимации. В каталог включены 286 записей с авторской последовательностью и редактируемыми параметрами из [зафиксированной версии OpenMotion](https://github.com/nexu-io/openmotion/tree/74a3d1e79d599673bc49e5e93aaa8707f1041804/library/templates/catalog). Тексты и ссылки берутся из русской и английской локалей. Полноразмерные референсы остаются у издателя. Проигрыватель получает код анимации из поставляемого API OpenMotion и передаёт таймкод в её renderAt. В базе знаний сохраняется версионный документ со стабильным идентификатором шаблона.

Мастер закрепляет шаблон и размещение графики на шаге материалов. Codex CLI составляет монтажный лист по исходникам и выбранному руководству через ограниченный MCP. Мост внутри монолита вызывает инструменты локального OpenMotion через его HTTP-диспетчер MCP. Studio создаёт проект из guideDraft, копирует исполняемый пример, принимает файлы из общего временного тома, сохраняет версию и экспортирует MP4. Тот же код анимации работает поверх клипов, на разделённом экране или в заставке. Оригинальный коммерческий ролик является референсом стиля. Ошибка экспорта видна в карточке ролика. Для существующих сборок без ID шаблона поддерживается их прежний монтажный лист и исполнитель.

OpenMotion запускается в Compose с закреплённым исходным кодом, постоянным рабочим томом и портом Studio на loopback. Серверные реквизиты, вход Codex и данные проектов находятся вне образа OpenMotion. Временные исходники удаляются после их импорта в Studio. ID проекта, версии и задания экспорта хранятся в состоянии сборки. После проверки рендера Content Mill сохраняет MP4 и openmotion.json в проектном хранилище.
