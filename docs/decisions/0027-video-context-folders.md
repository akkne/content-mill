# Папки контекста ролика

Окно материалов использует две панели. Дерево слева переключает текущую папку одним нажатием. Справа можно выделить отдельные строки или включить текущую папку целиком. Навигация сохраняет выбор до подтверждения.

Для нового ролика мастер заранее выбирает корневые папки «Промпты», «Бренд» и «Формулы роликов», если они есть в проекте. Закреплённые источники контекста проекта сохраняются. Пользователь может изменить набор.

При назначении персонажа мастер добавляет проектные папки выбранного аватара и его голоса. При замене или удалении персонажа мастер убирает автоматически добавленные папки, если их больше никто не использует. Материалы, выбранные вручную, сохраняются. Папки разрешений аватара исключены из автоматического подбора. Обзор перед запуском и запрос создания ролика используют один набор версий.
