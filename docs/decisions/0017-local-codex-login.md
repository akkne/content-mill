# 0017. Локальный вход в Codex через ChatGPT

Владелец локального экземпляра может подключить [Compose-конфигурацию входа](../../compose.codex-login.yaml). Бэкенд получает доступ на чтение к файлу авторизации Codex. На каждый вызов Astra адаптер читает актуальный вход и передаёт во временный профиль текущий токен доступа. Обновлением токена занимается Codex на компьютере. При повторном входе или замене файла авторизации пересоздайте контейнер бэкенда для обновления привязки файла.

Запросы пользователей этого экземпляра используют квоту подключённого аккаунта ChatGPT. При заданном OPENAI_API_KEY бэкенд предпочитает серверный ключ.
