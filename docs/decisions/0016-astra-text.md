# 0016. Общая модель для текстовой генерации

Для новых запросов без переопределения провайдера используем [GPT-6.2-Astra](../integrations/openai-gpt-6.2-astra.md) через Codex CLI с уровнем рассуждения high. Один выбор действует для подбора материалов, проектных сценариев и мастера ролика. Мастер получает сценарий, подпись и монтажный лист одним запросом. Сборка видеофайла остаётся демонстрационной.

Для существующих заданий очередь хранит идентификатор прежнего адаптера. Явно пустое значение провайдера сохраняет режим HTTP API, а значение claude включает Claude CLI.
