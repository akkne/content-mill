# 0010. Доступ Claude Code и Codex CLI к проекту

Владелец выдаёт из страницы проекта один сменяемый токен на час. Бэкенд хранит SHA-256 токена и проверяет срок, проект и владельца при каждом HTTP-запросе. Перевыпуск и отзыв действуют для всех клиентов, использующих этот токен.

MCP Python SDK обслуживает Streamable HTTP внутри FastAPI. Поиск обращается к каталогу PostgreSQL и возвращает ID версии. Текст и визуальное превью сервер получает из S3 по ключу этой версии. Для превью используются Pillow и PyAV. Клиенту достаточно URL и токена проекта. Ограничиваем ответ текстовым фрагментом или одним уменьшенным кадром, чтобы агент мог выбирать материалы до отправки в модель.
