# Режиссёрское описание каждого фрагмента

26 ноября 2026 года. Для нового короткого ролика сценарист пишет одну режиссёрскую заметку на каждый основной план. В заметке фиксируются композиция, привязка действия к словам и момент склейки. Раскадровка разворачивает заметку в самостоятельные задания на стартовый кадр и движение. Для белых вставок отдельно описываются макет и ход действия с локальными таймкодами. Ориентиры объёма относятся к визуальным указаниям; хронометраж реплик и склеек задаёт [правило ритма](0044-shot-rhythm.md).
