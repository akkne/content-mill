# 0008. Исходное фото образа и профиль речи персонажа

Дополнение к [стартовым промптам](0007-starter-prompts.md). Новый проект получает десятый документ в папке «Промпты / Аватар». [Промпт подготовки образа](../../backend/src/app/infrastructure/starter_prompts/10-character-look.md) составляет задание по описанию, фотографиям персонажа и необязательным референсам одежды.

Для будущего рабочего процесса фиксируем три решения. Агент получает бриф и полную опись приложенных версий файлов. У персонажа может быть несколько образов. Выбранное фото в одежде сохраняется в S3 отдельной версией и становится исходным изображением образа для следующих сцен. У говорящего есть назначенный голос проекта с ID ElevenLabs, а правила лексики и произношения можно приложить отдельным версионированным документом.

[Спецификация передачи](../video-agent-handoff.md) описывает действия пользователя, примеры JSON, зависимости этапов и проверки. Шаблоны для брифа, сценария, озвучки и раскадровки обновлены. Контракт задаёт будущую интеграцию, текущий мастер использует серверный мок.
