# 0006. Ролики внутри проекта

Библиотека роликов принадлежит проекту. FastAPI проверяет владельца, фильтрует библиотеку и хранит черновики, настройки формата и демонстрационные результаты. В мастере пользователь выбирает сохранённые версии документов и медиа. Источники контекста проекта отмечены при открытии мастера. Ролик запоминает выбранные версии и названия.

Сценарий вызывает операцию подготовки ролика через контракт `VideoGenerator`. [Серверный мок](../../backend/src/app/infrastructure/mock_video_generator.py) использует бриф, данные проекта и выдержки из выбранных документов. Демо-сборка показывает прогресс по серверному времени. Демо-публикация записывает статус и время в карточку. Внешние вызовы, очередь, синтез речи и рендер отложены.
