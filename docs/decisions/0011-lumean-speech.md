# 0011. Озвучка ElevenLabs через Lumean

Библиотека Content Mill хранит личные карточки и назначения в проекты. Каталог и синтез выполняет серверный адаптер Lumean с провайдером ElevenLabs. Прямой адаптер каталога отключён. На странице голоса владелец заказывает отдельную дорожку и получает временную ссылку. Оплачиваемый заказ получает локальный идентификатор до обращения к провайдеру. История и проверка статуса доступны после перезапуска. [Интеграция](../integrations/lumean-eleven-multilingual-v2.md)

Мастер ролика выбирает из голосов, назначенных проекту. Сценарий можно отправить на озвучку отдельным действием. Старые ролики без ссылки на личную карточку открываются как прежде.
