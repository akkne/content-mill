# 0019. Медиа через Polza AI

Рабочий аккаунт проекта находится в Polza AI. Для генерации стартовых кадров и видео используем его Media API и один серверный ключ. Идентификатор каждого заказа сохраняем перед опросом. Префикс провайдера в локальном идентификаторе исключает отправку старого заказа в другой API. При ручном повторе устаревшего заказа интерфейс показывает, что будет создан новый заказ. Бриф, монтаж Codex и хранение в проектном S3 сохраняют прежние контракты. [Кадры](../integrations/polza-nano-banana-2.1.md) · [Видео](../integrations/polza-veo-fast.md)
