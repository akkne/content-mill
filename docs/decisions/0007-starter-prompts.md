# 0007. Редактируемые стартовые промпты проекта

При создании проекта в его базе знаний появляются девять документов Markdown в восьми папках раздела «Промпты». Автор может открыть, изменить и версионировать каждый документ обычным редактором. Канонические тексты для новых проектов собраны в [отдельном каталоге бэкенда](../../backend/src/app/infrastructure/starter_prompts/). Копия принадлежит проекту. Создание проекта и запись первых версий выполняются вместе, при сбое записи объекты созданной попытки очищаются.

## Какие приёмы отобраны

Из редакционных материалов по длинным видео взяты операции, которые сохраняют смысл на одной фразе, сцене или коротком ролике. Таблица связывает каждый документ с конкретным приёмом и результатом, который можно проверить.

| Документ | Основание и адаптация для Content Mill |
| --- | --- |
| [Проверка фактов](../../backend/src/app/infrastructure/starter_prompts/01-facts.md) | Связь утверждения с источником и разделение наблюдения и вывода. В брифе фиксируются версия документа проекта, условия измерения и вопросы по расхождениям. |
| [Первый кадр и хук](../../backend/src/app/infrastructure/starter_prompts/02-hook.md) | Конкретная деталь открывает вопрос. Вариант начала принимается, если в доступных материалах есть кадр и ответ для финала. |
| [Сценарий и реплики](../../backend/src/app/infrastructure/starter_prompts/03-script.md) | Разговорная речь, проверяемые детали и завершение обещания. Многочастная структура сокращена до одной мысли. Реплики распределены между выбранными персонажами. |
| [Подготовка речи](../../backend/src/app/infrastructure/starter_prompts/04-speech.md) | Чистовой текст диктора и отдельный список сложных произношений. У каждой реплики указан назначенный голос проекта для ElevenLabs, а редакторские пометки отделены от текста для синтеза. |

| [Подбор кадров](../../backend/src/app/infrastructure/starter_prompts/06-assets.md) | Учёт происхождения и смысловых повторов. Кроп исходного фото считается повторным показом. Ведомость различает реальный товар, иллюстрацию и недостающий кадр. |

## Границы переноса

Длительность и формат берутся из брифа ролика, цвет и типографика — из правил бренда. Главы, длинные вступления, периодические рехуки, фиксированная сетка переходов, нормы повторов и предписанные уровни микса зависели от исходного формата. Для коротких роликов их не переносим.

Работа с персонажами адаптирована на уровне текста, голоса, образа и таймингов. Отдельные шаблоны синтеза лица, параметров lip-sync, передачи музыки в конкретный API и автопубликации требуют подтверждённых инструкций для этих операций. Каталог содержит только подготовленные этапы. Генератор роликов по-прежнему работает в демонстрационном режиме.

Стартовый набор заменяет прежние пустые категории при создании проекта. Старый универсальный пример «Сценарий.md» и его пустые папки площадок удалены из поставляемых примеров. Уже созданные документы могут содержать редакторские правки, поэтому обновление набора применяется к новым проектам.
