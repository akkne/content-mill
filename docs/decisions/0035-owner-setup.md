# Одноразовая настройка аккаунта владельца

Оператор выпускает приглашение командой `python -m app.issue_owner_setup` внутри backend и передаёт владельцу ссылку вида `/owner-setup#<токен>`. Срок действия составляет один час. Повторная выдача заменяет предыдущее приглашение для этого аккаунта.

После отправки формы mill обновляет почту и пароль существующего владельца, отзывает прежние сессии и открывает админ-панель. Погашение приглашения и создание сессии выполняются в одной транзакции. В базе хранится хеш токена. Фрагмент ссылки браузер передаёт приложению при отправке формы.
