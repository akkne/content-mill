# Причина остановки сборки ролика

Карточка ролика показывает фактический этап сбоя, номер сцены или реплики при наличии, локализованную причину, доступный HTTP-статус и распознанный код провайдера. Отдельно указано действие повтора: чтение существующего заказа, новая отправка, подготовка с моделью или локальная обработка.

При неудачном заказе сервис может вернуть HTTP 200 на запрос статуса. Модерация, включая отказ из-за публичной личности, определяется по ошибке задания. Отказ в доступе определяется отдельно. Сервер сохраняет в JSON ролика нормализованные данные; тексты запросов, необработанные ответы, подписанные ссылки и служебные трассировки в диагностику не входят. При повторном запуске предыдущая диагностика очищается. Для старых записей интерфейс понимает прежний код и показывает доступную информацию.
