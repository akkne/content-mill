# Личная библиотека аватаров и персонажи ролика

Личная библиотека использует закрытое пространство узлов владельца. Пользователь может создать персонажа до первого проекта, перетащить фотографии, описать образ, завести предметы одежды, приложить документ с разрешением на использование изображения и голоса и выбрать голос по умолчанию. При добавлении в проект сервер копирует актуальные версии и назначает голос из библиотеки владельца. Проектная копия редактируется независимо. Существующие проектные аватары доступны в мастере сразу.

Порядок строк мастера определяет «Персонаж 1», «Персонаж 2». В строке редактор может заменить голос для данного ролика или оставить персонажа без реплик. Сервер проверяет владельца, проект, уникальность имён и назначение голоса. Снимок в settings.characters и brief.json связывает имена с ID проектных персонажей, роли файлов с версиями, голоса с внешними ID и моделями. Явно отмеченная версия имеет приоритет над последней версией того же файла. Одна версия передаётся один раз. Разрешения хранятся отдельно от автоматически передаваемых референсов. Проектный MCP читает версии по существующему маршруту.

В сценарии с выбранными персонажами раскадровка указывает ID видимых персонажей и говорящего в каждой реплике. Для говорящего в кадре планируется кадр с одним видимым лицом. Монтаж диалога может чередовать такие планы. Для каждого видимого персонажа нужен визуальный референс. Lumean синтезирует каждую реплику по закреплённой паре voice_id и model_id. FFmpeg декодирует речь и расставляет её по интервалам. Избыточно длинная реплика останавливает сборку. HeyGen получает исходный клип и WAV только с речью в кадре. После синхронизации сервер кладёт на полученный клип полную дорожку сцены, включая закадровые реплики. Чисто закадровый текст обходится без HeyGen. В истории сохраняются исходник, отдельные реплики, дорожка и синхронизированный клип. Финальный монтаж работает с этой версией. Без выбранных персонажей сохраняется прежний режим Veo.
