# Назначение аватара в проект с неполным деревом

При назначении аватара сервер находит активную папку с ролью «Аватары». Если она отсутствует, сервер создаёт её в корне проекта. Для аватара с назначенным голосом то же правило применяется к папке «Голоса». Если имя уже занято пользовательским узлом, новая папка получает числовой суффикс. Создание папок и копирование аватара выполняются под блокировкой проекта в одной транзакции.

Личная библиотека отображает сохранённые назначения после повторного открытия. «Разрешения» служат для добровольного хранения копии согласия. Пустая папка допускается при назначении и сборке ролика. [Библиотека аватаров](0021-avatar-cast.md).
