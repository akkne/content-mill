# Схема API рядом с адаптером модели

Для каждой пары провайдера и модели ведём спецификацию `<имя_адаптера>.api.md` рядом с Python-модулем. В ней фиксируем структуру входа и результата, ограничения провайдера и приложения, обработку ошибок и правила повтора. Карточка в каталоге интеграций сохраняет прежний адрес и ссылается на эту спецификацию. Документация отключённых адаптеров остаётся рядом с кодом. [Регламент интеграций](../integrations/README.md)

При чтении готового кадра Polza вернула список файлов в data. Официальный пример показывает объект. Для одиночного результата обработчик принимает обе формы. Тесты проверяют получение кадра и клипа по сохранённому ID, в том числе при непригодном ответе. [Контракт получения кадра](../../backend/src/app/infrastructure/polza_nano_banana.api.md)
