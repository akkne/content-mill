# 0033. Ведущий HeyGen Avatar 6 и монтаж через подписку Codex

Для пилота используем [Avatar 6 Turbo](../integrations/heygen-avatar-6.md) в 1080p и [GPT-6.2-Sol](../integrations/openai-gpt-6.2-sol.md) с высоким уровнем рассуждения. Участки с говорящим ведущим собираются из первого кадра и дорожки речи. Сохранённая дорожка проекта сохраняет также закадровые реплики. При выключенной настройке ролик собирается прежним способом. В мастере доступна длительность 20 секунд для проверки стоимости и сравнения результатов.

Codex получает раскадровку и выбирает монтажные решения, FFmpeg собирает файл. Пилот для владельца проекта использует квоту его подписки. Перед публичным доступом потребуется выбрать способ оплачивать генерации клиентами.
