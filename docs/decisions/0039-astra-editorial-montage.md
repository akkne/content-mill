# Речь и монтаж по референсу проекта

По умолчанию сценарий, раскадровку и монтаж готовит GPT-6.2-Astra с уровнем рассуждения high. Для новых сценариев с персонажами mill сохраняет читаемые интервалы сцен и реплики с именем и режимом подачи. Перед заказом исходников сборщик сверяет эти данные с раскадровкой. При расхождении он один раз запрашивает исправление. Прежние сценарии в свободной форме остаются доступны.

Примеры двух стилей хранятся отдельно для каждого проекта. На сервере каталог `/etc/mill/style-guides/<UUID проекта>` содержит хронологические подборки кадров `facts.jpg` и `story.jpg`. Выбор стиля добавляет соответствующую подборку к запросам на сценарий, раскадровку и монтаж. Для проекта без подборки действуют текстовые указания. Референс служит образцом визуального языка.

Монтажный лист поддерживает плавное приближение плана, несколько фотографий из выбранных материалов, смену выделения в списке и круговую диаграмму для произнесённой доли. Сборщик проверяет источник, интервалы и совпадение подписей с речью. Фотографии персонажа исключены из автоматических фотовставок. Графику рисует сам сборщик. Отдельных заказов на генерацию фотографий эта версия не создаёт.
