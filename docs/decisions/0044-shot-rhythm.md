# Планы по 3–4 секунды и полноэкранные пояснения

26 ноября 2026 года. Новый мастер сохраняет версию ритма в настройках ролика. Сценарий содержит по одному интервалу на основной план. Для заданной длительности в секундах количество основных планов равно округлённому вверх результату деления на четыре. Длительность каждого плана составляет 3000–4000 мс. Например, раскадровка на 30 секунд содержит восемь планов. Бэкенд сверяет время, реплики и смену ракурса или крупности до заказа кадров. Для старых черновиков действуют их исходные правила. При продолжении сборки число сцен берётся из сохранённой раскадровки.

GPT получает бриф, монтажные заметки, референсы и расшифровку с таймкодами. Для объяснения конкретного действия модель выбирает интервалы внутри речи по 1000–2000 мс. Каждый такой фрагмент — отдельный вертикальный рисунок и анимация на белом фоне. Вставка закрывает весь кадр, в том числе лицо. Монтаж сохраняет единую дорожку голоса и часы субтитров. Несколько пояснений возможны в одном ролике. Референсы или бриф задают содержание. Для загруженной записи с одного ракурса крупность меняется цифровым кадрированием. При генерации с нуля модель задаёт точку съёмки каждого плана.

Для новых заказов синтеза добавленных пользователем голосов приложение передаёт ElevenLabs скорость 1,2 и выразительность style 0,4. Это действует и при использовании сохранённого шаблона Lumean. Исходная запись спикера использует собственный звук.
