# 0028. Отложить HeyGen в сборке роликов

Veo создаёт исходный клип с артикуляцией по сценарию. ElevenLabs через Lumean озвучивает реплики назначенными голосами. FFmpeg укладывает их по таймкодам и заменяет звуковую дорожку клипа. Точность совпадения движений губ с новым голосом зависит от исходника Veo.

При повторе остановленной раскадровки воркер использует этот же процесс. Старые этапы ожидания HeyGen продолжаются с озвучки сохранённого клипа. Если обработанный клип уже сохранён, он доступен для наложения звука.
