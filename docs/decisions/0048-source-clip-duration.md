# 0048. Минимальная длительность исходного клипа

HeyGen Video 1 получает заказ на десятисекундный дубль. Провайдер может вернуть более длинный файл. При получении сервер проверяет, что видео и звук покрывают монтажное окно сцены. Например, при `keep_ms = 3750` подходит дубль длиной 10,125 секунды. Полный исходник сохраняется в проекте, а в монтаж идут первые 3750 мс. Если одна из дорожек заканчивается раньше нужной границы, сцена получает ошибку `invalid_clip`.
