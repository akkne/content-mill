# Речь, раскадровка иллюстраций и прозрачные анимации

Этапы 4 и 5 и пример в каталоге обновлены в [решении 0043](0043-gpt-motion.md).

Новые рилсы из мастера получают версию монтажа в настройках ролика. Для ранее сохранённых сборок исполнитель читает прежние монтажные листы. Все этапы работают в очереди монолита.

1. Пользователь выбирает запись спикера из MP4 или WebM в материалах проекта либо заказывает исходные сцены по брифу. Для записи локальный Whisper возвращает слова с таймкодами. GPT предлагает до трёх фрагментов с завязкой и выводом, выбирает один и указывает диапазоны исходной речи. FFmpeg вырезает их в указанном порядке и сохраняет вертикальный черновой монтаж. Для сгенерированных сцен тот же этап использует утверждённые интервалы раскадровки.
2. Whisper распознаёт звуковую дорожку чернового монтажа. Content Mill объединяет слова в короткие титры по пунктуации, длине и паузам. Расшифровка и титры доступны в папке сборки.
3. GPT получает фразы, кадр спикера, контекст бренда и выбранные материалы. Монтажный план связывает каждую иллюстрацию с репликами, описывает композицию, движение и положение поверх спикера. Завязка и паузы между акцентами остаются с субтитрами.
4. Nano Banana генерирует отдельный макет для каждой иллюстрации на однотонном зелёном фоне. GPT проверяет смысл и читаемость. После проверки всех макетов начинается анимация.
5. Kling получает каждый макет отдельным заказом на пять секунд с указаниями по движению и шумовым эффектам. FFmpeg подгоняет движение к интервалу фразы, удаляет зелёный фон и сохраняет WebM с альфа-каналом. Проверка кадров контролирует наличие прозрачной области и видимого объекта. После сбоя опрос продолжается с записанного номера заказа.
6. OpenMotion собирает дорожку спикера, иллюстрации и субтитры. Клипы спикера заполняют весь вертикальный кадр. Для покадрового экспорта Studio получает прозрачные кадры иллюстрации одним PNG и переключает их по часам композиции. Эффекты звучат на −18 дБ, выбранная по брифу музыка на −20 дБ. Готовые файлы — `final.mp4`, `edit.json` и квитанция `openmotion.json`.

Пример «Спикер с иллюстрациями» использует фрагмент ответа астронавта о воде на Марсе. Обе языковые версии сохраняют оригинальный звук. Для примера подготовлены два отдельных анимированных изображения Марса и локализованные титры. [Исходное интервью NASA, 19 июля 2023](https://images.nasa.gov/details/iss069m262001424_Expedition_69_Education_Inflight_Big_Brothers_and_Sisters_of_Wyoming_230719).
