# HeyGen Video 1

Генератор исходных видеосцен. Получает первый кадр, промпт с действием и репликами, возвращает MP4 со звуком. Применяется для роликов с персонажами и без них. Для выбранной синхронизации ведущего используется [Avatar 6](heygen-avatar-6.md). Анимации для монтажа создаёт GPT. [Контракт адаптера](../../backend/src/app/infrastructure/providers/media/heygen_video.api.md).
