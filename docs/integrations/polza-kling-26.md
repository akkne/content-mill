# Kling 2.6 через Polza AI

Активный генератор видеосцен. Получает стартовый PNG от Nano Banana и промпт со временем окончания действия. Для сцены запрашивает десятисекундный дубль со звуком, для отдельной иллюстрации — пятисекундную анимацию с шумовыми эффектами.
