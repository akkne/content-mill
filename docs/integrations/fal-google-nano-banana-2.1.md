# Nano Banana 2.1 через fal

Статус — отключён после перехода на Polza AI. Прежний адаптер рассчитан на работу при наличии серверного FAL_KEY. Контракт проверен 21 ноября 2026 года. Для нового кадра используется POST https://fal.run/google/nano-banana-2.1, для работы с образами и товарами — тот же путь с суффиксом /edit. Авторизация Key. Аккаунту нужен доступ к обоим endpoint и средства на генерацию. [Генерация](https://fal.ai/models/google/nano-banana-2.1/api) · [Редактирование](https://fal.ai/models/google/nano-banana-2.1/edit/api)

Приложение запрашивает один PNG, 1K, 9:16. Передаёт prompt до 4000 символов и до четырёх JPEG-референсов и кадр первой сцены через image_urls в формате data URI. Размер base64 равен четырём байтам на каждые три исходных с округлением вверх по числу групп. Отдельных системных инструкций и пользовательских URL нет. Синхронный ответ содержит images[].url. Сервер сразу скачивает результат и проверяет PNG, предел приложения 8 МБ для следующей операции Veo. Общие лимиты HTTP-запроса и ответа в битах и предел промпта провайдера в символах в схеме не указаны.

Цена зависит от использованных токенов. Квота, доступ и модерация применяются со стороны fal. Таймаут также возможен после списания. Автоматического повтора платного POST нет. Копия результата хранится в проектном S3 независимо от срока жизни URL провайдера. Для теста нужен один стартовый кадр.
