# OpenAI GPT-6.2-Astra через Codex

Активная модель для новых текстовых запросов Content Mill — `gpt-6.2-astra`. На 21 ноября 2026 года локальный каталог Codex CLI содержит эту модель и уровень рассуждения `high`. Доступ и квоты зависят от аккаунта.

[Адаптер](../../backend/src/app/infrastructure/astra_script.py) вызывает Codex CLI 0.170.0 в отдельном временном каталоге. Инструкции передаются через конфигурацию, текст через stdin, превью JPEG через файлы. CLI записывает финальный текст в UTF-8. При завершении процесса Content Mill удаляет каталог. При отказе провайдера операция завершается ошибкой. Новый запуск повторно расходует квоту.

Общие ограничения числа символов, размера обмена в битах и размера результата для этой модели через CLI не подтверждены. Доступность, тариф и условия обработки данных определяет аккаунт OpenAI.
