# Veo 3.1 Fast в Polza AI

Статус — активна. На 21 ноября 2026 года каталог содержит `google/veo3_fast`. POST /api/v1/media принимает серверный Bearer POLZA_API_KEY, модель, async=true и input. Передаём стартовый PNG в images с типом base64, режим FIRST_AND_LAST_FRAMES_2_VIDEO, 9:16 и enableTranslation=false для сохранения языка реплик. Звук генерируется вместе с клипом, а сервер проверяет наличие аудио перед монтажом. Гайд указывает 2000 символов промпта, текущий каталог указывает 60 000. Приложение для новых сцен использует меньший предел. Общий предел запроса и ответа в битах не опубликован. [Гайд](https://polza.ai/docs/gaidy/veo-3-1) · [Каталог API](https://polza.ai/api/v1/models)

Ответ содержит ID для GET /api/v1/media/{id}. При completed скачиваем MP4 по data.url без авторизации, ограничиваем 64 МиБ, затем сохраняем в проект. Файлы у провайдера хранятся семь дней. Тарификация за видео, права, баланс и квоты зависят от аккаунта. Опрос возобновляется по сохранённому ID. Повторная отправка после отказа либо потери ответа может списать средства. [Модель и тариф](https://polza.ai/models/google/veo3_fast) · [Адаптер](../../backend/src/app/infrastructure/polza_veo_fast.py)
