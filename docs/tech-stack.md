# Технологический стек Content Mill

## Согласовано

| Часть | Технология | Роль |
| --- | --- | --- |
| Серверная часть | Python | Единое монолитное приложение с предметной логикой. |
| Интерфейс | Next.js, TypeScript | Страницы и серверные возможности интерфейса. |
| Стили | Tailwind CSS | Стили нового приложения с опорой на [дизайн-токены](DESIGN.md). |
| Локальный запуск | Docker, Docker Compose | Контейнеризация и запуск приложений. |
| Демо | HTML, CSS, JavaScript | Существующий автономный [прототип](../frontend-mvp/index.html); не часть будущего стека приложения. |

Формулировка «бэкенд Next.js» здесь означает серверные возможности веб-приложения, например рендеринг страниц. Основная серверная логика проекта пишется на Python, как зафиксировано в [архитектуре](architecture.md).

## Пока не выбрано

Python-фреймворк, база данных, ORM или другой способ доступа к данным, очередь задач, хранилище файлов, провайдеры AI и соцсетей, тестовые и сборочные инструменты. Не добавляй их в обязательный стек до отдельного решения и реализации.
