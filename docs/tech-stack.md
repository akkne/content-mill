# Технологический стек Content Mill

## Согласовано

| Часть | Технология | Роль |
| --- | --- | --- |
| Серверная часть | Python, FastAPI, SQLAlchemy ORM, Alembic, Psycopg, Argon2id | Один монолит с чистой архитектурой; сейчас работают `/health` и сессии. |
| Интерфейс | Next.js, TypeScript | Страницы и серверные возможности интерфейса. |
| Стили | Tailwind CSS | Обязателен для всех экранов и компонентов Next.js, включая новые. См. [правила оформления](code-style.md#nextjs-и-tailwind-css). |
| Данные пользователей | PostgreSQL | Сейчас аккаунты, сессии, проекты, контекст, дерево папок и метаданные версий; далее роли, связи, статусы и журналы генерации. |
| Файлы и документы | S3-совместимое объектное хранилище | Содержимое всех документов, исходники, изображения, аудио, видео и артефакты генерации. Локально используется S3Mock как S3-эмулятор; продакшен-провайдер будет выбран отдельно. |
| Локальный запуск | Docker, Docker Compose | Контейнеризация и запуск приложений. |
| Демо | HTML, CSS, JavaScript | Автономные [прототипы](../frontend-mvp/README.md); не часть будущего стека приложения. |

Формулировка «бэкенд Next.js» здесь означает серверные возможности веб-приложения, например рендеринг страниц. Основная серверная логика проекта пишется на Python, как зафиксировано в [архитектуре](architecture.md).

## Пока не выбрано

Продакшен-провайдер S3 и провайдеры соцсетей. Для генерации сценариев монолит использует [очередь PostgreSQL и API Claude или Codex](decisions/0013-managed-scripts.md). PostgreSQL доступен через реализации репозиториев на SQLAlchemy ORM; Psycopg остаётся драйвером. Модели — источник схемы, миграции ведёт Alembic. Для проверок используются pytest и Ruff на сервере, ESLint и TypeScript во фронтенде. Не добавляй остальные технологии в обязательный стек до отдельного решения и реализации. Разделение данных между PostgreSQL и S3 описано в [кратком роадмапе](implementation-roadmap.md).

В первом этапе используются случайные access и refresh токены с хранением хешей в PostgreSQL и доставкой браузеру через HttpOnly cookie Next.js. Модель сессий описана в [основе бэкенда](backend-foundation.md).
